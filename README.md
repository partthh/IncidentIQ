# IncidentIQ — AI-Assisted Incident Management Platform

IncidentIQ is a real-time incident management platform built with **Java 21, Spring Boot, PostgreSQL, React, and TypeScript**. It ingests service telemetry, detects and correlates incidents using configurable rules, and provides AI-assisted investigations with evidence-backed recommendations.

The platform features JWT-based authentication, role-based access control, real-time updates through WebSockets, incident lifecycle management, and an auditable event timeline. Its deterministic AI provider enables end-to-end demonstrations without requiring external API keys.

**Key focus:** Reliable incident detection, explainable AI assistance, secure operations, and real-time incident response.
